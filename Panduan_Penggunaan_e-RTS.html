1. Pendahuluan

e-RTS (e-Rapor Tengah Semester) adalah aplikasi desktop luring (offline) yang dirancang khusus untuk mempermudah Wali Kelas dan Guru Mata Pelajaran dalam mengolah nilai, menyusun leger ranking kelas, serta mencetak rapor tengah semester secara cepat, rapi, dan terstruktur.

Fitur Baru di v1.1.0: Sistem anti-freeze (in-app toast notification), dukungan penuh nilai 0, tombol "Tidak Remedi", Leger Nilai lengkap dengan ranking dan ekspor Excel, total nilai dan ranking di format cetak rapor, serta fitur Backup & Restore database.

2. Instalasi & Update Aplikasi

  1. Siapkan file installer: Installer e-RTS 1.1.0 by SIGIE Lab.exe.
  2. Klik dua kali (double click) pada file installer tersebut.
  3. Ikuti petunjuk pemasangan hingga selesai. Jika Anda sudah pernah menginstal versi 1.0.0, installer v1.1.0 akan otomatis memperbarui aplikasi Anda tanpa menghapus data nilai yang sudah ada.
  4. Buka aplikasi melalui pintasan (shortcut) di Desktop atau Start Menu.

3. Pengaturan Awal Sekolah (Setup Guard)

Pada versi 1.1.0, aplikasi menerapkan Setup Guard. Seluruh menu operasional di sidebar terkunci hingga data pengaturan awal dilengkapi:

  1. Buka menu Pengaturan (ikon gerigi) pada panel menu di sebelah kiri.
  2. Lengkapi tab 1. Data Sekolah: Nama Sekolah, Nama Kepala Sekolah, ID/NUPTK/NIP Kepala Sekolah, Tahun Ajaran, dan Semester.
  3. Lengkapi tab 2. Pengaturan Cetak: Nama Wali Kelas, ID/NUPTK/NIP Wali Kelas, Kelas/Rombel, Tempat Cetak, dan Tanggal Cetak Rapor. (Unggah logo dan tanda tangan bersifat opsional).
  4. Klik tombol Simpan Pengaturan. Aplikasi akan menampilkan notifikasi sukses dan otomatis langsung membuka menu Dashboard dengan seluruh menu yang telah terbuka.

4. Mengelola Data Siswa

Anda dapat memasukkan data siswa dengan dua metode:

A. Menggunakan Import Excel Dapodik (Direkomendasikan)

  1. Buka menu Siswa di sidebar kiri.
  2. Klik tombol Impor Data Dapodik (Excel).
  3. Pilih file Excel dari Dapodik. Sistem akan otomatis mendeteksi kolom NISN, Nama, dan Jenis Kelamin, serta menyediakan pilihan filter Rombel/Kelas.

B. Menambah Secara Manual

  1. Ketikkan NISN, Nama Lengkap, dan pilih Jenis Kelamin (L/P), lalu klik Simpan.
  2. Tersedia fitur edit dan hapus per siswa dengan konfirmasi modal yang aman.

5. Mengelola Mata Pelajaran

  1. Buka menu Mata Pelajaran.
  2. Generate Standar: Pilih Kurikulum (Merdeka atau K13) dan Jenjang (SD, SMP, SMA, SMK), klik Tampilkan, lalu pilih mapel yang ingin ditambahkan secara otomatis.
  3. Manual: Ketik nama mata pelajaran dan pilih kategorinya (Wajib atau Muatan Lokal), lalu klik Tambah.

6. Input Nilai & Fitur Tidak Remedi

  1. Masuk ke menu Input Nilai.
  2. Pilih mata pelajaran yang ingin diinput dari menu dropdown di bagian atas.
  3. Input Nilai 0 (Nol): Angka 0 diakui sebagai nilai sah dan tidak akan terhapus.
  4. Tombol "Tidak Remedi": Jika siswa di kelas Anda tidak mengikuti remedial atau nilainya tuntas, klik tombol Tidak Remedi (Samakan Nilai). Aplikasi akan otomatis mengisi kolom Nilai Remidi sama persis dengan Nilai Asli untuk seluruh siswa!
  5. Template Excel: Anda juga dapat mengklik Download Template Excel, membagikannya ke guru mapel, lalu mengimpornya kembali melalui tombol Import Excel.
  6. Klik tombol Simpan Nilai di bawah tabel.

7. Kehadiran & Catatan Siswa

  1. Buka menu Kehadiran.
  2. Masukkan jumlah ketidakhadiran: Sakit (S), Izin (I), dan Tanpa Keterangan (A).
  3. Ketikkan evaluasi atau motivasi pada kolom Catatan Wali Kelas.
  4. Klik tombol Simpan Kehadiran di kanan atas.

8. Leger Nilai & Ranking Kelas (Fitur Baru)

  1. Buka menu Leger Nilai di sidebar kiri.
  2. Aplikasi secara otomatis menghitung nilai akhir setiap mata pelajaran, Total Nilai, Rata-Rata Nilai, dan Peringkat (Ranking) kelas.
  3. Tiga siswa peringkat teratas akan ditandai dengan lencana khusus: 🥇 Peringkat 1, 🥈 Peringkat 2, dan 🥉 Peringkat 3.
  4. Klik tombol Export Leger ke Excel untuk menyimpan rekapitulasi nilai seluruh kelas ke dalam file Excel (.xlsx).

9. Mencetak Rapor (Satuan & Masal)

  1. Buka menu Cetak Rapor.
  2. Total & Peringkat di Rapor: Lembar rapor secara otomatis mencantumkan baris Jumlah Nilai, Rata-Rata, dan Peringkat Kelas siswa.
  3. Preview & Cetak Satuan: Pilih siswa dari dropdown, klik Preview Rapor, lalu klik Cetak Siswa Ini.
  4. Cetak Masal Seluruh Kelas: Klik tombol Cetak Semua Siswa. Aplikasi akan menyusun lembar rapor seluruh kelas dengan pemisah halaman otomatis (page-break) siap cetak sekaligus.

10. Cadangkan & Pulihkan Data (Backup & Restore)

  1. Buka menu Pengaturan lalu klik tab 3. Backup & Restore.
  2. Cadangkan Data (Backup): Klik tombol Simpan Cadangan Database untuk menyimpan salinan database (.sqlite) ke flashdisk atau folder cadangan Anda.
  3. Pulihkan Data (Restore): Jika Anda berpindah laptop atau ingin mengembalikan data lama, klik tombol Pilih File untuk Dipulihkan dan pilih file cadangan Anda.
