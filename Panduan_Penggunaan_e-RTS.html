1. Pendahuluan

e-RTS (e-Rapor Tengah Semester) adalah aplikasi desktop luring (offline-first) yang dirancang khusus untuk mempermudah Wali Kelas dan Guru Mata Pelajaran dalam mengolah nilai, menyusun leger nilai lengkap dengan ranking kelas, serta mencetak lembar rapor Penilaian / Sumatif Tengah Semester (PTS/STS) secara cepat, rapi, dan terstruktur.

Ikhtisar Pembaruan Versi 1.1.0: Aplikasi v1.1.0 menghadirkan arsitektur anti-freeze berbasis floating toast dan modal in-app, pengakuan penuh angka 0 sebagai nilai sah, tombol satu klik "Tidak Remedi", modul Leger Nilai lengkap dengan pemeringkatan kelas otomatis (🥇, 🥈, 🥉) & ekspor Excel, format cetak rapor presisi 1 halaman penuh A4 standar arsip/jilid map (skala 100% bebas downscale), serta fitur cadangkan dan pulihkan database lokal (Backup & Restore).

2. Instalasi & Update Aplikasi

  1. Siapkan file installer resmi: Installer e-RTS 1.1.0 by SIGIE Lab.exe.
  2. Klik dua kali (double click) pada file installer tersebut.
  3. Pilih direktori instalasi yang diinginkan atau biarkan pada pengaturan bawaan, lalu klik Pasang / Install.
  4. Jika Anda sebelumnya telah menginstal versi 1.0.0, installer v1.1.0 akan otomatis memperbarui aplikasi tanpa menghapus atau mengubah database data siswa dan nilai yang telah Anda input.
  5. Buka aplikasi melalui pintasan (shortcut) di Desktop atau Start Menu komputer Anda.

3. Pengaturan Awal Sekolah (Setup Guard)

Untuk menjamin integritas data dan mencegah cetak rapor tanpa identitas resmi, aplikasi menerapkan Setup Guard. Seluruh menu operasional di sidebar kiri terkunci dengan indikator abu-abu hingga pengaturan awal dilengkapi:

  1. Buka menu Pengaturan (ikon gerigi) pada panel menu di sebelah kiri.
  2. Lengkapi isian pada tab 1. Data Sekolah: Nama Sekolah, Nama Kepala Sekolah, Jenis Identitas (NIP/NUPTK/PegID), Nomor ID Kepala Sekolah, Tahun Ajaran, dan Semester.
  3. Lengkapi isian pada tab 2. Pengaturan Cetak: Nama Wali Kelas, Jenis Identitas, Nomor ID Wali Kelas, Kelas/Rombel, Tempat Cetak, dan Tanggal Cetak Rapor.
  4. Logo & Tanda Tangan (Opsional tapi Direkomendasikan): Unggah logo sekolah, tanda tangan digital wali kelas, serta stempel/tanda tangan kepala sekolah berformat JPG/PNG untuk otomatis tersemat di lembar cetak rapor.
  5. Opsi Peringkat Kelas: Anda dapat mengaktifkan atau menonaktifkan centang "Tampilkan Peringkat Kelas di Lembar Rapor Siswa" sesuai kebijakan sekolah.
  6. Klik tombol Simpan Pengaturan. Aplikasi akan menampilkan notifikasi sukses dan otomatis langsung membuka menu Dashboard dengan seluruh menu operasional yang telah terbuka penuh.

4. Mengelola Data Siswa

Anda dapat memasukkan data siswa dengan dua metode praktis:

A. Menggunakan Import Excel Dapodik (Direkomendasikan)

  1. Buka menu Siswa di sidebar kiri.
  2. Klik tombol Impor Data Dapodik (Excel).
  3. Pilih file Excel yang diunduh dari Dapodik atau rekap sekolah. Sistem secara cerdas akan mendeteksi baris judul, kolom NISN, Nama Siswa, Jenis Kelamin (L/P), dan Rombel Saat Ini.
  4. Pilih kelas yang relevan dari menu dropdown filter rombel, lalu klik Mulai Impor.

B. Menambah Secara Manual

  1. Ketikkan NISN, Nama Lengkap, dan pilih Jenis Kelamin (L/P) pada formulir di sebelah kiri, lalu klik Simpan.
  2. Tersedia tombol Edit dan Hapus per siswa yang dilindungi konfirmasi dialog in-app yang aman.
  3. Tersedia pula tombol Reset Siswa untuk mengosongkan seluruh data siswa sekaligus jika Anda ingin memulai tahun ajaran baru.

5. Mengelola Mata Pelajaran

  1. Buka menu Mata Pelajaran di sidebar kiri.
  2. Preset Kurikulum Otomatis: Pilih Kurikulum (Kurikulum Merdeka atau K13) dan Jenjang (SD, SMP, SMA, SMK), klik Tampilkan, lalu pilih mata pelajaran standar nasional yang ingin dimasukkan sekaligus.
  3. Penambahan Manual: Ketikkan nama mata pelajaran secara manual dan tentukan kategorinya:
    • A. Mata Pelajaran Wajib: Kelompok mata pelajaran inti kurikulum nasional.
    • B. Muatan Lokal: Kelompok mata pelajaran kedaerahan (seperti Bahasa Jawa, Bahasa Sunda, PLHJ, dsb).
  4. Mata pelajaran yang telah ditambahkan dapat diubah namanya, disesuaikan kategorinya, maupun dihapus sewaktu-waktu.

6. Input Nilai & Fitur "Tidak Remedi"

  1. Masuk ke menu Input Nilai di sidebar kiri.
  2. Pilih mata pelajaran yang ingin diisi nilainya dari menu dropdown di bagian atas.
  3. Input Langsung di Tabel: Ketikkan Nilai Asli dan Nilai Remidi (skala 0–100) langsung pada tabel siswa.
  4. Dukungan Penuh Nilai 0 (Nol): Angka 0 diakui secara sah sebagai nilai numerik valid dan tidak akan hilang atau berubah menjadi strip. Kosongkan kolom jika siswa memang belum dinilai.
  5. Tombol Pintas "Tidak Remedi": Apabila seluruh siswa di kelas Anda tuntas atau tidak mengikuti program remedial, klik tombol Tidak Remedi (Samakan Nilai). Sistem akan langsung menyalin seluruh Nilai Asli ke kolom Nilai Remidi secara otomatis!
  6. Bekerja Offline via Excel: Anda dapat mengklik Download Template Excel untuk membagikan blangko penilaian kepada guru mapel, lalu mengunggahnya kembali ke aplikasi melalui tombol Import Excel.
  7. Klik tombol Simpan Nilai di bawah tabel untuk menyimpan ke database.

7. Kehadiran & Catatan Siswa

  1. Buka menu Kehadiran di sidebar kiri.
  2. Masukkan akumulasi ketidakhadiran tengah semester untuk masing-masing siswa:
    • S: Sakit (dengan surat keterangan)
    • I: Izin (dengan pemberitahuan orang tua)
    • A: Tanpa Keterangan / Alpha
  3. Ketikkan motivasi belajar, pesan perkembangan kepribadian, atau catatan akademik pada kolom Catatan Wali Kelas.
  4. Klik tombol Simpan Kehadiran di bagian kanan atas layar.

8. Leger Nilai & Ranking Kelas

  1. Buka menu Leger Nilai di sidebar kiri.
  2. Sistem secara otomatis menghitung matriks nilai seluruh siswa dari semua mata pelajaran:
    • Nilai Akhir: Ditentukan dari Nilai Remidi (jika ada) atau Nilai Asli.
    • Total Nilai: Jumlah akumulatif seluruh nilai akhir mata pelajaran.
    • Rata-Rata Nilai: Nilai rata-rata perolehan siswa.
    • Peringkat (Ranking): Pemeringkatan otomatis berdasarkan Total Nilai tertinggi.
  3. Tiga siswa peringkat teratas akan dianugerahi lencana penghargaan: 🥇 Juara 1, 🥈 Juara 2, dan 🥉 Juara 3.
  4. Klik tombol Export Leger ke Excel untuk mengunduh rekap nilai lengkap satu rombel berformat .xlsx yang siap dicetak atau dilaporkan ke pihak kurikulum/kepala sekolah.

9. Mencetak Rapor (Satuan & Masal)

Format cetak rapor e-RTS v1.1.0 telah disempurnakan secara presisi (pixel-perfect) agar tepat memenuhi 1 halaman penuh kertas A4 standar arsip dinas resmi:

Spesifikasi Cetak Ukuran / Standar Keterangan
Ukuran Kertas A4 Portrait (210 × 297 mm) Pas 1 halaman penuh (tanpa overflow ke halaman 2)
Margin Halaman Atas: 1.2 cm | Bawah: 1.25 cm
Kiri: 1.85 cm | Kanan: 1.85 cm		 Standar Jilid Map & Arsip (memberi ruang jepit map)
Rasio Skala Render 100% Murni (No-Downscale) Konten melebar penuh 17.3 cm, garis tajam dan proporsional
Peringkat Kelas 1 Baris Lurus Mendatar Peringkat ke-X dari Y Siswa (berwarna biru rapi)
Susunan Tanda Tangan 2 Tingkat Simetris Atas: Orang Tua & Wali Kelas | Bawah: Kepala Sekolah & Stempel
  1. Buka menu Cetak Rapor di sidebar kiri.
  2. Kontrol Peringkat Langsung: Centang atau hilangkan centang "Tampilkan Peringkat Kelas" di bagian atas untuk mengatur kemunculan baris ranking pada lembar rapor saat itu juga.
  3. Cetak Satuan (Per Siswa): Pilih nama siswa dari menu dropdown, klik Preview Rapor, lalu klik tombol Cetak Siswa Ini.
  4. Cetak Masal Seluruh Kelas (Batch Printing): Klik tombol Cetak Semua Siswa. Aplikasi akan menyusun lembar rapor seluruh siswa dalam kelas dengan pembatas halaman otomatis (auto page-break). Anda cukup memilih printer fisik atau opsi "Save as PDF" pada jendela print Windows.

10. Cadangkan & Pulihkan Data (Backup & Restore)

  1. Buka menu Pengaturan, lalu klik tab 3. Backup & Restore.
  2. Cadangkan Data (Backup): Klik tombol Simpan Cadangan Database. Pilih folder penyimpanan aman (misalnya Flashdisk, Harddisk Eksternal, atau Cloud Drive). Berkas cadangan akan disimpan dengan penamaan otomatis bertanggal (misal: Backup_eRTS_2026-10-20.sqlite).
  3. Pulihkan Data (Restore): Jika Anda mengganti komputer, menginstal ulang Windows, atau ingin mengembalikan data ke titik sebelumnya, klik tombol Pilih File untuk Dipulihkan dan pilih berkas .sqlite cadangan Anda. Seluruh data sekolah, siswa, nilai, dan tanda tangan akan kembali seketika.

11. Catatan Riwayat Perubahan (Changelog)

Versi 1.1.0 (Rilis: 20 Oktober 2026)
RILIS TERBARU

🌟 Sorotan Pembaruan: Peningkatan Stabilitas Anti-Freeze, Leger Nilai & Ranking Kelas, Backup/Restore, dan Cetak Rapor Pixel-Perfect A4.

  • Stabilitas Sistem Notifikasi & Dialog Anti-Freeze: Menghapus seluruh fungsi alert() dan confirm() bawaan Windows yang menyebabkan form dan keyboard terkunci (freeze). Menggantinya dengan Floating In-App Toast dan Custom Promise Modal Dialog yang mulus dan non-blocking.
  • Perbaikan Pemulihan Fokus Jendela File Dialog: Memperbaiki seluruh dialog file Electron (unggah logo, stempel, template excel, backup) agar jendela utama otomatis mendapatkan kembali fokus keyboard setelah dialog ditutup.
  • Perbaikan Dukungan Penuh Nilai 0 (Nol): Memperbaiki logika evaluasi nilai sehingga angka 0 diakui sebagai nilai sah pada input tabel, ekspor/impor Excel, perhitungan leger, dan lembar cetak rapor.
  • Fitur Baru Modul Leger Nilai & Ranking Kelas: Menambahkan menu navigasi baru untuk melihat matriks nilai seluruh siswa dan seluruh mata pelajaran dalam satu layar, lengkap dengan perhitungan otomatis total nilai, rata-rata, peringkat kelas dengan lencana medali (🥇, 🥈, 🥉), serta tombol ekspor leger ke format Excel (.xlsx).
  • Fitur Baru Tombol Pintas "Tidak Remedi": Tombol satu klik di menu input nilai untuk menyalin seluruh Nilai Asli ke Nilai Remidi bagi kelas yang siswanya tuntas tanpa mengikuti remedial.
  • Fitur Baru Setup Guard & Alur Terarah: Mengunci menu navigasi secara visual sebelum data sekolah dilengkapi, dan otomatis mengarahkan pengguna langsung ke Dashboard setelah pengaturan awal disimpan.
  • Fitur Baru Fitur Backup & Restore Database: Fasilitas pencadangan dan pemulihan snapshot database SQLite lokal melalui tab Pengaturan.
  • Fitur Baru Indikator Kelengkapan Mapel di Dashboard: Kartu hijau di dashboard yang merangkum mata pelajaran mana saja yang pengisian nilainya telah mencapai 100% tuntas.
  • Tata Letak Format Cetak Rapor A4 Standar Arsip (Single Page Fit):
    • Desain pas 1 halaman penuh A4 (210 × 297 mm) tanpa kelebihan halaman kedua.
    • Margin presisi Jilid Map/Arsip: Atas 1.2 cm, Bawah 1.25 cm, Kiri 1.85 cm, Kanan 1.85 cm.
    • Rendering skala murni 100% tanpa distorsi kompresi atau auto-downscale browser.
    • Teks peringkat kelas tampil lurus dalam 1 baris utuh (whitespace-nowrap).
    • Susunan tanda tangan 2 tingkat yang proporsional dengan stempel otentik menimpa garis nama di dasar halaman.
    • Kontrol visibilitas baris peringkat kelas (dapat dinyalakan/dimatikan di Pengaturan maupun saat Preview Cetak).
  • Dukungan Integrasi Trakteer Sukarela: Popup apresiasi berkala dan tautan langsung untuk mendukung kelanjutan pengembangan aplikasi mandiri melalui teer.id/nur_wahid_musthofa.
