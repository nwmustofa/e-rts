1. Pendahuluan

e-RTS (e-Rapor Tengah Semester) adalah aplikasi desktop luring (offline) yang dirancang khusus untuk mempermudah Wali Kelas dan Guru Mata Pelajaran dalam mengolah nilai serta mencetak rapor tengah semester secara cepat, rapi, dan terstruktur.

Keunggulan Utama: 100% Offline (tanpa internet), data tersimpan aman di laptop/komputer, mendukung import Excel, dan format cetak langsung pas di kertas A4.

2. Instalasi Aplikasi

  1. Siapkan file installer: Installer e-RTS 1.0.0 by SIGIE Lab.exe.
  2. Klik dua kali (double click) pada file installer tersebut.
  3. Ikuti petunjuk pemasangan hingga selesai (opsional: tentukan folder tujuan instalasi).
  4. Setelah selesai, pintasan (shortcut) aplikasi akan otomatis muncul di Desktop atau Start Menu komputer.

3. Pengaturan Awal Sekolah

Sebelum memasukkan data nilai, sangat dianjurkan mengisi data pengaturan terlebih dahulu:

  1. Buka menu Pengaturan (ikon gerigi) pada panel menu di sebelah kiri.
  2. Lengkapi formulir yang tersedia:
    • Identitas Sekolah: Nama Sekolah, Tahun Ajaran, dan Semester.
    • Identitas Kelas: Nama Wali Kelas, NUPTK/NIP Wali Kelas, Nama Kepala Sekolah, NUPTK/NIP Kepala Sekolah, dan Nama Rombel/Kelas.
    • Logo & Tanda Tangan: Anda dapat mengunggah (upload) gambar Logo Sekolah, Stempel/Tanda Tangan Wali Kelas, dan Kepala Sekolah. (Jika tidak diupload, kolom tanda tangan akan otomatis dikosongkan untuk tanda tangan basah secara manual).
    • Tempat & Tanggal Cetak: Contoh: Jakarta, 12 Oktober 2026.
  3. Klik tombol Simpan Pengaturan di kanan atas halaman.

4. Mengelola Data Siswa

Anda dapat memasukkan data siswa dengan dua metode:

A. Menggunakan Import Excel (Direkomendasikan)

  1. Buka menu Siswa di sidebar kiri.
  2. Klik tombol Import Data Excel.
  3. Pilih file Excel yang berisi daftar siswa. Sistem akan otomatis mendeteksi kolom NISN, Nama, dan Jenis Kelamin. Anda juga dapat memfilter siswa berdasarkan Rombel/Kelas jika dalam satu file Excel terdapat banyak kelas.

B. Menambah Secara Manual

  1. Klik tombol Tambah Siswa.
  2. Ketikkan NISN, Nama Lengkap, dan pilih Jenis Kelamin (L/P), lalu simpan.
  3. Tersedia juga fitur edit dan hapus langsung di tabel daftar siswa.

5. Mengelola Mata Pelajaran

  1. Buka menu Mata Pelajaran.
  2. Klik tombol Tambah Mapel.
  3. Masukkan nama mata pelajaran (misal: Pendidikan Pancasila, Matematika) serta pilih kategorinya (Wajib atau Pilihan).
  4. Kategori ini menentukan pengelompokan tabel mata pelajaran pada lembar cetak rapor.

6. Input Nilai & Kehadiran

A. Pengisian Nilai Mata Pelajaran

  1. Masuk ke menu Penilaian.
  2. Pilih mata pelajaran yang ingin diinput nilainya melalui menu pilihan di bagian atas.
  3. Metode Cepat (Template Excel):
    • Klik Download Template Excel. Aplikasi akan mengunduh file Excel yang telah terisi nomor urut, NISN, dan nama seluruh siswa di kelas Anda.
    • Buka file Excel tersebut, isi kolom Nilai Asli dan Nilai Remidi (jika ada).
    • Kembali ke aplikasi e-RTS dan klik Import Nilai dari Excel.
  4. Metode Manual: Anda juga bisa langsung mengetikkan angka nilai pada tabel di layar, lalu klik Simpan Nilai.

B. Pengisian Data Kehadiran & Catatan

  1. Buka menu Kehadiran.
  2. Isi rekap ketidakhadiran siswa: Sakit (S), Izin (I), dan Tanpa Keterangan (A).
  3. Isi kolom Catatan Wali Kelas untuk evaluasi/motivasi perkembangan siswa serta kolom Tanggapan Orang Tua (jika diperlukan).
  4. Klik tombol Simpan Absensi di sudut kanan atas.

7. Mencetak Rapor

  1. Buka menu Cetak Rapor.
  2. Tabel akan menampilkan daftar seluruh siswa beserta kelengkapan nilainya.
  3. Cetak Per Siswa (Satuan):
    • Klik tombol Preview (ikon mata) di baris siswa yang bersangkutan.
    • Periksa tampilan lembar rapor yang telah disesuaikan dengan standar kertas A4.
    • Klik tombol Cetak (Print) di pojok kanan atas untuk langsung mencetak ke printer atau menyimpan sebagai PDF.
  4. Cetak Masal Seluruh Kelas (Batch Print):
    • Dari halaman daftar siswa, klik tombol biru Cetak Semua Siswa.
    • Aplikasi akan menggabungkan seluruh lembar rapor siswa dalam satu antrean cetak dengan pemisah halaman otomatis (page break) per siswa.
